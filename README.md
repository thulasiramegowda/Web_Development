## 🚀 What Does This Project Do?

The IPL Ticket Booking System is a web application where users can:

- View available IPL matches.
- Enter their details to book tickets.
- Select their preferred stadium and stand.
- Preview their ticket details.
- View their booking history.
- Store and retrieve booking information using Supabase.

## 💻 Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project:

```bash
cd ipl-ticket-booking
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_publishable_key
```

Start the development server:

```bash
npm run dev
```

**Note:** Never commit your actual `.env` file or secret/service-role keys to GitHub. Configure your Supabase database and appropriate RLS policies before using the application.
